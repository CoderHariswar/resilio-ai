# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive feedback gracefully, and focus
on what is best for the community. Harassment, personal attacks, and discriminatory language are not
tolerated in issues, pull requests, discussions, or any other project space.

Report unacceptable behaviour privately to the maintainers through a
[GitHub Security Advisory](https://github.com/CoderHariswar/resilio-ai/security/advisories/new)
(mark it "Code of Conduct"). All reports are reviewed and kept confidential. Maintainers may remove
content or ban participants who violate this code, as described in the Covenant's enforcement guidelines.
